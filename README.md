# Side-by-Side Markdown Live Editor & Previewer — Gamility Tools

A modern, high-speed, split-screen GitHub-Flavored Markdown (GFM) editor and real-time HTML renderer with document metrics, formatting shortcut toolbars, offline autosave recovery, and multi-format exports.

---

## 🔒 100% Client-Side Privacy Guarantee

All document editing, string parsing, and HTML rendering execute **strictly within your local web browser**. Your notes, technical specifications, draft articles, and private code blocks are **never transmitted, logged, or uploaded** to external servers or remote cloud APIs.

---

## ✨ Features

- **Split-Screen Synchronous Workspace**:
  - Live side-by-side editing: Raw Markdown on the left, rich rendered HTML preview on the right.
  - Three view modes: **Split View**, **Editor Only**, and **Preview Only** (ideal for mobile or distraction-free reading).
- **GitHub-Flavored Markdown (GFM) Support**:
  - Headings (H1 through H6) with smooth typography.
  - Tables with column alignment syntax (`| Col | Col |`).
  - Interactive task checklists (`- [x] Done`, `- [ ] Pending`).
  - Fenced code blocks with language indicators and one-click copy buttons.
  - Blockquotes, warning callouts, horizontal dividers, and strikethrough (`~~text~~`).
  - Inline code, links, images, ordered and unordered nested lists.
- **Rich Formatting Shortcut Toolbar**:
  - Quick buttons for Bold, Italic, Strikethrough, Heading levels, Quote, Code, Link, Image, Lists, and Table insertion.
  - Smart tab key indentation and multi-line selection indent/outdent.
- **Real-Time Document Analytics**:
  - Live Word count, Character count, Reading time estimation (~200 WPM), and Heading count.
- **Autosave Draft Recovery**:
  - Automatically preserves active documents in browser `localStorage` (`gamility_markdown_draft`) to protect against accidental refreshes or browser crashes.
- **Export & Download Engine**:
  - **Download Markdown File (`.md`)**.
  - **Download Rendered Webpage (`.html`)** complete with clean styling.
  - **Copy Raw Markdown** to clipboard.
  - **Copy Clean HTML Markup** to clipboard.
- **Responsive Dark Design**: Tailored glassmorphism UI styled for desktop, tablet, and mobile displays.
